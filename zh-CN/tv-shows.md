电视剧使用与电影相同的源目录和批次控件。每个符合条件的顶层目录只占一个批次名额，包含所有嵌套的季。发现阶段的视频必须大于 100 MiB。

| 源文件示例 | 解释 |
| --- | --- |
| `11.22.63/11.22.63-01.mkv` 到 `-08.mkv` | 连续编号的剧集；LLM 识别系列并推断缺失的季号。 |
| `12-Monkeys/12-Monkeys-S01E01.mkv` | 明确的季号与集号，即使只有一个视频。 |
| `Slow-Horses/season-2/...S02E05...`，以及其他季目录 | 一个系列选择，跨季分别映射单集。 |
| `Show 1x01`、`Show S01 E01`、`Show-S01-E01`、`Show Season 1 Episode 01` | 其他明确的季/集编号写法。 |
| `Show/season-1/show.103.hdtv.mp4` | 紧凑集号从季目录获得上下文；直接发行目录中的显式集号也可用于识别视频。 |
| `Black Lagoon 01 The Black Lagoon.mkv` | 带标题、同系列前缀和编号的集数。 |

电视剧模式优先于双文件电影模式。LLM 不能修改文件名明确给出的季号和集号。编号文件必须具有一致的系列前缀，且集号映射唯一。第 0 季允许作为特别篇。支持数字开头的剧集标题，例如 `S01E01 1200 A.M.` 或 `Season 2 Episode 09 - 4 Days Out`。

即使目录中的其他视频无法匹配，发现阶段仍会选出可识别的单集。花絮、制作特辑、合并多集的视频、重复映射及与所在季目录冲突的文件保留在源位置。它们的字幕不会重新分配给已选择的剧集。被跳过的视频会出现在 Match Results，扫描事件报告选中和跳过数量。清理会保留剩余媒体或字幕。

文件名的标题前缀能阻止明显放错位置的其他剧集混入父级系列。如果混合目录包含多个不同系列且没有唯一对应的父标题，则不会匹配；应把每个系列放在源目录的单独直接子目录中。混合目录里未补零的电影续集编号不会误判为电视剧。发现规则仍要求每个视频只有一集，不改写冲突的季号或集号。要对以前扫描过的目录应用新规则，请启动新批次。

电视剧识别分为**两个阶段**。第一阶段，LLM 接收 `find -ls` 列表，通过 `submit_tv_series` 仅提交系列名称和置信度。TMDB 按名称搜索，不筛选年份。多个候选使用既有的 LLM 选择对话；没有结果则重试系列识别，不搜索相邻年份。手工 TMDB ID 更正也可先确定系列身份，再映射剧集。界面展示的年份总是来自选中的 TMDB 记录，绝不取自 LLM 猜测。

第二阶段使用新的对话，提供已确认的系列名称与年份、文件夹上下文，以及在 JSON 中按 `1`、`2` 等数字编号的排序后相对文件名。这个提示不提供完整服务器路径或原始 `find -ls` 输出。模型只返回**数字文件 ID、季号和集号的映射**，不能更改系列身份。后端自行分配 ID，并将其映射到精确的原始路径，因此 LLM 无须重写文件名。每个 ID 必须出现且仅出现一次。映射和完成标记一起保存。映射未解决时不移动文件。每个已映射单集在导入前都会与 TMDB 的季/集元数据核对；未知单集留在源位置，其他有效单集仍可完成。

Event Log 和 Current Task 区分系列识别、候选选择、剧集映射和导入，批次在各阶段分别显示 **Series identified**、**Episodes mapped** 和 **Imported**。

## 目的目录与命名

批次在电影目的目录之外，还保存同级的 `tv` 目的目录。默认电影目录对应的电视剧目录为 `/exports/disk1/archive/media/tv`。

例如：

```text
tv/
  Slow Horses (2022)/
    Season 02/
      Slow Horses (2022) S02E05 - Boardroom Politics.mkv
      Slow Horses (2022) S02E05 - Boardroom Politics.srt
```

系列名称、年份及单集标题均来自 TMDB。如果文件名规范化删除了整个单集标题（例如仅为 `/`），文件名就在季/集编号处结束，媒体目录仍保留原始标题。SRT 采用原有确定性配对规则，有歧义的字幕继续保持未解决。移动操作采用硬链接和源文件名移除，不复制或回读视频内容。目标路径已有文件时必须明确执行 **Replace Local Media**。

## 检查点与媒体目录

电视媒体目录包括系列、季、集、剧集文件、系列/集演职员、图片及独立的类型表。人物和演职员角色与电影共享。电影与电视剧使用不同的 ID 命名空间，包括媒体目录 URL。

每集的媒体目录记录与工作区检查点在源文件名移除前一起提交。重启后可完成已经提交的移动，不重复导入成功的单集。某集失败不会回滚已成功的集。源目录清理仍为递归操作：任意层级中只要还有受支持媒体、SRT 或指向子目录的符号链接，就保留整个源目录树。

媒体目录搜索和最近添加项包含电视剧。系列页面展示已导入的剧集及已保存的简介、播出日期、片长、剧照、可展开的演职员与本地文件。批次 Match Results 显示每个视频的剧集映射及导入结果。

安装与升级操作应用电视剧数据库结构并部署新提示和模块。此功能不会修复或重新分类已经完成的电影批次。
