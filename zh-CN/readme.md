# R3el

本项目的介绍发布在 [https://r3el.osoyalce.com](https://r3el.osoyalce.com/)。

R3el 使用 [LlamaSrv](https://llamasrv.osoyalce.com/) 运行本地 Qwen 模型。
请按照 [LlamaSrv 仓库](https://github.com/NadimGhaznavi/llamasrv)的说明单独安装和管理模型服务。
R3el 默认连接 LlamaSrv 的推理端口 `51001`；参见[安装与模型设置](/zh-CN/pages/one-batch-identification/)。

如果喜欢这个项目，欢迎在 [GitHub](https://github.com/NadimGhaznavi/r3el) 仓库右上角点一颗星。
