# R3el

Інформація про цей проєкт опублікована на [https://r3el.osoyalce.com](https://r3el.osoyalce.com/).

R3el використовує [LlamaSrv](https://llamasrv.osoyalce.com/) для локальної моделі
Qwen. Встановлюйте й обслуговуйте сервіс моделі окремо за інструкціями з
[репозиторію LlamaSrv](https://github.com/NadimGhaznavi/llamasrv). R3el типово
підключається до порту інференсу LlamaSrv `51001`; див.
[встановлення й налаштування моделі](/uk/pages/one-batch-identification/).

Якщо вам подобається проєкт, поставте йому зірку на [GitHub](https://github.com/NadimGhaznavi/r3el) (у верхньому правому куті сторінки репозиторію).
