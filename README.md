# R3el

The information in this project is published on [https://r3el.osoyalce.com](https://r3el.osoyalce.com).

R3el uses [LlamaSrv](https://llamasrv.osoyalce.com/) to run its local Qwen model.
Install and manage the model service separately using the
[LlamaSrv repository](https://github.com/NadimGhaznavi/llamasrv). R3el connects
to LlamaSrv's inference port `51001` by default; see
[installation and model setup](pages/one-batch-identification.md#llamasrv-model-service).
