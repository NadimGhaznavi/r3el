# R3el

[Documentation index](index.md) · [Batch flowcharts](pages/flowchart.md)

AI-assisted media cataloging for local movie and TV collections.

The installer starts `r3el-control.service`, serving the Catalogue at
`http://<server>:42220/`, Control at `/control`, and the Event log at `/events`. See [Control server](pages/control-server.md) for
filters, event details, and standalone startup.
