# R3el

[Documentation index](index.md) · [Batch flowcharts](pages/01-high-level-flow.md)

AI-assisted media cataloging for local movie and TV collections.

The installer starts `r3el-control.service`, serving the event log at
`http://<server>:42220/`. See [Control server](pages/control-server.md) for
filters, event details, and standalone startup.
